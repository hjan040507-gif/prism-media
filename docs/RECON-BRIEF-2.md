## 할 일
`~/prism-media/<proj>/RECON.md` 하나만 쓴다(이 폴더 밖에는 아무것도 쓰지 않는다). 형식은 `~/prism-media/byclick/RECON.md` 와 같은 절 구성:
0. 먼저 알아야 할 것(촬영 방식을 바꾸는 사실) · 1. 스택·실행(로컬 실행에 필요한 것: node 버전, env 변수 이름, 빌드 명령, 로컬 Supabase 가능 여부 — supabase/migrations·seed 유무, `supabase` CLI 2.117 은 ~/bin 에 있음) · 2. 라이브 주소·상태(`curl -sI` GET/HEAD 만) · 3. 지시 항목 ↔ 실제 라우트·컴포넌트(file:line) · 4. 테스트·관리자 계정(파일 경로와 변수 이름만, 값은 읽지도 출력하지도 않는다) · 5. 쓰기 위험(GET 인데 서버가 쓰는 경로, 열람 기록·조회수·속도 제한 카운터·접근 로그, 외부 유료 호출) · 6. 가림 대상(셀렉터 힌트) · 7. 사실 후보(지시의 '사실' 항목마다 값과 근거 file:line, 근거 없으면 '미확인') · 8. 브랜드(주색 hex·폰트, 근거 file:line) · 9. 다른 세션 점유(그 레포에 rc 세션·서버·worktree 가 도는지, `ps`·`ss -ltnp` 읽기만) · 10. 지시와 코드가 다른 점(지시엔 있는데 없는 화면, 이름이 다른 기능 — 한 줄씩, 근거 file:line) · 추천 촬영 경로(운영 공개 화면 / 로컬 사본+가짜 응답 / 로컬 Supabase / 기존 캡처, 결정은 메인 세션).
마지막 답은 10번 절 내용 그대로 + 추천 촬영 경로 3줄 + 막힌 것(20줄 이내).

## 안전
- 고객 레포(`~/<repo>`)는 읽기만. 파일 쓰기·git 상태 변경(checkout·stash·worktree add·fetch 포함) 금지. `npm install`·빌드·서버 실행·도커 실행도 이 단계에선 하지 않는다.
- 운영 사이트는 GET/HEAD(`curl`)만, 로그인 금지. 서버가 GET 에 쓰는 경로(조회수·열람 기록)는 열지 말고 코드로만 본다.
- 비밀값(.env* 값·토큰·비밀번호)은 읽거나 출력하지 않는다. `.env.example`·코드의 `process.env.X` 이름으로 변수 목록만 만든다.
- 남의 세션·프로젝트의 프로세스와 포트는 건드리지 않는다. 종료·재시작은 이 세션이 띄운 PID 만, 포트가 차 있으면 빈 포트를 쓴다.
- 대기에 while/until+sleep 을 쓰지 않는다. 큰 출력은 head 로 자른다. `.next`·`node_modules`·`dist` 는 읽지 않는다.
- 종료 시각: 시작 후 30분. 그때까지 못 본 항목은 '미확인'으로 두고 끝낸다.
