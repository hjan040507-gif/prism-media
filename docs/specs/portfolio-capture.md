- 모든 PNG 옆에 같은 이름 .json: 보이는 제목·버튼·입력·링크·카드·이미지의 사각형(CSS px)과 글자, scrollY, 뷰포트

- media/에 로고 원본(svg·png), 히어로·제품 원본 사진·영상. brand.json에 코드에 있는 실제 주색 hex와 폰트 이름
- 채팅 위젯·쿠키 배너·개발 배지·Vercel 툴바·스크롤바는 숨기고 찍는다
- 파일은 개당 95MB 미만, 프로젝트 폴더 400MB 안쪽, Git LFS는 쓰지 않는다(용량 과금 소지)
