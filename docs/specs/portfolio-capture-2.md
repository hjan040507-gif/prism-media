<대상 — 이 순서로, 프로젝트 하나가 끝날 때마다 push>
1. okjob(오케이잡 제주, 계절근로자 배정·급여 시스템)
- 데스크톱: 월간 대시보드(가동률 히트맵), 배정하기(가용 인원 자동 계산·자동 추천·중복 배정 경고), 기간 배정, 저장된 배정 4탭(일별·월별·근로자별 매트릭스·기간), 급여 계산기, 입금 확인, 알림톡 발송 관리, 설정(단가표)
- 모바일(PWA): 홈, 배정하기
- 상태 흐름: 배정하기(농가 선택→작업·시간→근로자 칩 선택→저장 직전), 매트릭스 칸 hover 행·열 강조
- 파일: 일별 배정표·근로자별 매트릭스 엑셀을 열어 첫 화면을 PNG로
- 운영 DB엔 실제 근로자 이름·여권 정보가 있고 소장이 지금도 쓰고 있다. 운영엔 로그인하지 말고(민감정보 열람 기록이 남는다) worktree + 로컬 Supabase(도커)에 마이그레이션과 개발 시드를 넣어 찍는다. 시드·마이그레이션 명령은 접속 주소가 로컬인지 출력으로 확인한 뒤에만 돌린다(운영에서 돌면 3기 근로자 데이터가 지워진다). 로컬이 안 되면 docs/manual 사용설명서의 원본 캡처를 쓰고 BLOCKED.md에 적는다
- 사실: 계약 기능 수, 엑셀에서 옮긴 배정 건수, 알림톡 템플릿 수, 자동 시험 수
2. matchsat(매치샛, 위성영상 익명 매칭 B2G)
- 데스크톱: 메인, 수요 등록, 수요 목록·입찰, 지정 매칭, 주문 수정(입찰 0건일 때), 관리자(회원 승인·정지, 신고 처리, 매칭 재지정) / 모바일: 메인, 수요 목록
- 상태 흐름: 수요 등록 단계, 입찰 제출 전·후
- 기관명·담당자·계좌는 가린다
- 사실: 매칭 전 신원·계좌 비공개를 DB 권한으로 막는 근거(정책·뷰 이름과 경로), 입찰·주문 수정 규칙
- 계약서·견적서 파일이 프로젝트에 있으면 비밀유지·결과물 공개 제한 조항 원문을 facts.md 끝에 인용한다(포트폴리오 게재 판단용)
3. hanil(한일금속공업 홈페이지 + CMS)
- 데스크톱: 메인(히어로), 인사말·연혁·인증, PRODUCT 랜딩(공정 체계도), 공정 상세 3종 이상, 설비현황 3탭, R&D·ESG, 고객지원(문의·견적 폼) / 모바일: 메인, 공정 상세
- 관리자: 사진 교체(슬롯 선택→초점 지정 미리보기), 문구 수정, 문의·견적 접수함. 관리자 계정은 고객에게 넘어갔으니 운영엔 로그인하지 말고 worktree 로컬 + 로컬 DB 가짜 데이터로 찍는다. 안 되면 BLOCKED.md
- seq: 히어로 크로스페이드, 공정 체계도 → 상세 이동
- 사실: 페이지 수, 공정 수, 사진 교체 슬롯 수, 기획서 원문 대조 결과, 접근성 점수
4. eureka(유레카 설비 & 누수탐지)
- 데스크톱·모바일: 랜딩(지역명 파라미터 2종), 견적 신청 폼(사진 첨부 단계), 실시간 작업 현황판, 게시판 목록·글
- 관리자: 접수 목록, 상태 4단계 변경, 접수 상세(고객 정보 가림)
- seq: 히어로 일러스트 캐러셀
- 사실: 상태 단계, GA4 이벤트 수, 게시글 검색 최적화 자동 적용 방식
5. sy-motors(SY모터스 카카오톡 접수 챗봇)
- 재료는 실제 카카오톡 화면이다. 프로젝트 폴더·QA 기록에 있는 실단말 캡처(접수 흐름·완료 요약·담당자 전달 버튼·알림톡)를 먼저 찾아 가림 규칙대로 가려 쓴다
- 없으면 worktree에서 봇 엔진을 로컬로 돌려(DB·카카오·문자 호출 전부 가짜) 방문정비·사고/긴급·장애문의 3개 흐름의 실제 응답 JSON(말풍선 글·버튼·카드)을 순서대로 states/에 저장한다. 운영 스킬 주소로는 요청을 보내지 않는다(접수 행이 생기고 대표에게 알림이 간다)
- 사실: 접수 카테고리 수, 전화번호 검사 규칙, 사진 최대 장수, 알림 분기
6. pscompany(PS COMPANY 회사 사이트 + 지원자 관리)
- 공개 화면(홈·크리에이터·모집·연락)은 이미 있으니 관리자(지원자 목록·상세·모집 직군 관리), 지원서 작성 흐름(직군 선택→정보 입력→사진 첨부→제출 직전, 제출은 가로챔), 모바일 지원 폼만 찍는다
- 지원자 사진은 얼굴이라 흐리게, 이름·연락처는 가린다
- 사실: 모집 직군 수, 지원서 항목 수
7. edubily(카페24 구매대행몰)
- 데스크톱·모바일: 메인, 카테고리, 상품 상세 2종. 카페24 관리자 화면은 우리가 만든 게 아니라 찍지 않는다
- 사실: 상품·상세페이지 수, 카테고리 정리 전후 수
8. switin(스윗인 회사·제품 소개)
- 데스크톱·모바일: 메인, 회사 소개, 제품 소개, 문의 폼(제출은 가로챔), 관리자 제품 추가 화면(기존 계정이 있을 때만, 없으면 로컬)
9. soopon(숲ON페스타 2026 캠페인 랜딩)
- 데스크톱·모바일: 메인, 숲ON 처방전 필터 단계(고민·동반자·지역·일정), 결과 목록, 프로그램 상세, B2B 비즈 페이지, 상담 신청 폼(가로챔)
- seq: 필터를 고를 때 결과가 바뀌는 장면
- 외부 예약 링크 주소 글자는 가린다
10. waylog(웨이로그, 안드로이드 + 웹 PWA)
- 지금 Google Play에 나간 버전 기준. 웹 PWA(390×844·DSF 3)로 홈 피드, 리뷰 상세, 8주 챌린지, AI 인바디 분석 결과(저장된 결과만, 새로 부르지 않는다), 푸시 알림 설정, 관리자 게시물 관리. Play 스토어 스크린샷 원본이 있으면 media/에

- 사실: 챌린지 기간, 푸시 종류 수, 비공개 테스트 인원·기간
